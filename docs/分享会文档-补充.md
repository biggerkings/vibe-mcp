## 二、技术补充篇

### 2.1 样式映射技术细节

#### 设计稿单位 → Web 单位转换

| 源单位 | 转换公式 | 输出单位 | 说明 |
|:---|:---|:---|:---|
| px (设计稿) | `value / baseUnit` | rem | 基准 375px = 3.75rem |
| px (字体) | `value / baseUnit` | rem | 保持可读性 |
| hex | 直接映射 | 保留 hex | 或映射到设计令牌 |
| rgba | 直接映射 | rgba | 保留透明度 |
| pt (字体) | `value * 1.333` | px | iOS 单位转换 |

#### 设计令牌映射表

| DSL Token | CSS Variable | Value |
|:---|:---|:---|
| `$colors.primary` | `--color-primary` | `#E57423` |
| `$colors.background` | `--color-background` | `#FFFFFF` |
| `$colors.text` | `--color-text-primary` | `#333333` |
| `$spacing.md` | `--spacing-md` | `0.24rem` |
| `$typography.h1.size` | `--font-size-h1` | `0.44rem` |
| `$borderRadius.lg` | `--radius-lg` | `0.32rem` |

### 2.2 组件识别算法

#### 启发式规则示例

```typescript
// 按钮识别规则
const buttonRules = [
  { condition: 'hasText && isClickable && hasPadding', weight: 0.9 },
  { condition: 'hasBorderRadius && hasBackgroundColor', weight: 0.7 },
  { condition: 'name.contains("button")', weight: 0.8 }
]

// 输入框识别规则
const inputRules = [
  { condition: 'hasBorder && hasPlaceholder', weight: 0.9 },
  { condition: 'height <= 56 && width >= 200', weight: 0.6 },
  { condition: 'name.contains("input")', weight: 0.8 }
]
```

### 2.4 环境配置步骤

```bash
# 1. 安装 MCP Server
npm install -g @mastergo/mcp

# 2. 配置 Cursor MCP
# 在 ~/.cursor/mcp.json 中添加:
{
  "mcpServers": {
    "user-mastergo-magic-mcp": {
      "command": "npx",
      "args": ["-y", "@mastergo/mcp@latest"],
      "env": {
        "MASTERGO_API_TOKEN": "your-token"
      }
    }
  }
}

# 3. 验证配置
# 在 Cursor 中输入: "列出可用的 MCP 工具"
```

### 2.5 Troubleshooting 速查

| 问题 | 可能原因 | 解决方案 |
|:---|:---|:---|
| MCP 工具不显示 | 配置未加载 | 重启 Cursor |
| DSL 拉取为空 | fileId 错误 | 确认文件分享权限 |
| 代码生成失败 | DSL 格式异常 | 简化设计稿图层 |
| 样式还原度差 | Token 未匹配 | 检查 variables.scss |
| 浏览器 MCP 失败 | 无活跃浏览器 | 先调用 browser_navigate |
